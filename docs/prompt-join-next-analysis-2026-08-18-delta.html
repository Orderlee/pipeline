08결론

문서를 그대로 실행하면 안 된다. 다만 폐기가 아니라 4건 교체다: 분석 3(디바운스)·9(백필)은 버리고, 2(전이)는 축을 frames_captions 로 갈고, 4(wave prune 재현)를 1순위로 올린다. 1(GT)은 문서 판정대로 최우선이지만 대상이 sourcei 감사에서 frames 리뷰큐로 옮겨간다.

§01·§02·§03의 판단은 전부 살아 있다 — GT가 분모라는 것, 제품 규칙은 분포 IoU라는 것, 프레임 micro가 표본을 과장한다는 것, 승자문장 UMAP은 재시도 금지라는 것. 8일간 40여 커밋이 들어갔지만 판단이 뒤집힌 것은 하나도 없고, 전제 데이터가 바뀐 것이 셋이다.

검증 방식 — 라이브 FiftyOne(docker-analysis-1, 2026-08-18) · prod Postgres(docker-postgres-1) · git log/rev-list · /data/fiftyone/{sourcei,frames_bank,sourceh_v2} 산출물 직접 판독. 서브에이전트 보고 없음 — 전부 결정론 도구 1차 실측.
